# 公司价值决策系统

基于本体建模的公司研究与估值框架

这个仓库用于沉淀一类公司的研究笔记：

- 不只是做模型
- 不只是做聊天助手
- 而是试图把企业数据、业务对象、流程、权限、Agent、执行动作连接起来
- 最终形成“可理解、可分析、可决策、可追踪”的公司价值决策系统

## 我们重点研究什么

每家公司重点回答下面这些问题：

1. **它的数据底座是什么**
   - 数据仓库
   - 对象模型
   - 图谱
   - 本体
   - 工作流状态

2. **它怎么定义业务世界**
   - 是表驱动
   - 是对象驱动
   - 是流程驱动
   - 还是本体驱动

3. **它怎么让 AI 真正参与业务执行**
   - 只读分析
   - 给建议
   - 自动触发流程
   - 多 Agent 协作执行

4. **它怎么做权限与治理**
   - 哪些数据能看
   - 哪些动作能做
   - 谁批准
   - 是否可追踪、可回放、可审计

5. **它怎么形成决策闭环**
   - 数据输入
   - 模型理解
   - 决策建议
   - 动作执行
   - 结果反馈
   - 持续优化

6. **怎么把这套方法用到公司研究与估值**
   - 公司有哪些核心对象
   - 这些对象怎么相互作用
   - 哪些变量驱动收入、毛利、资本开支、估值
   - 哪些事件会改变市场预期
   - 哪些信号能形成可持续跟踪的判断框架

## 当前判断

这一类公司真正有价值的，不是“谁模型更强”，而是：

- 谁能把企业真实业务世界建模出来
- 谁能把 AI 接到真实流程上
- 谁能让建议变成动作
- 谁能让整个系统可治理、可追踪、可复盘

这也是我们研究它们的主要原因。

而对我们自己的研究实践来说，最重要的不是复述这些公司的产品介绍，而是：

- 能不能把一家公司的经营现实抽成稳定对象
- 能不能把行业变量、资本开支、供需、技术代际、政策约束放进同一张图
- 能不能把“看新闻”变成“更新对象状态与关系”
- 能不能让估值判断变成一套可维护、可迭代的公司价值决策系统
